# 会话消息目录

2026-10-14 源码增量，已生成本地开发安装包，尚未更新 GitHub 发布。

会话目录按回合列出用户输入和模型回复。每项显示明确角色文字与内容摘要，模型回复增加缩进线；回合编号保持原值，标题计数仍表示回合数。同一回合的模型过程消息合为一个目录入口，摘要和定位使用最后一条非空模型消息；回复中更新此入口，结束后通常对应最终答复，不跨回合合并。正文保留完整过程。空白消息与工具调用不额外占用目录；没有可读消息的回合保留原有状态入口。

点击消息先定位所属虚拟回合，再定位该消息正文。定位等待虚拟列表挂载与尺寸稳定，切换路线、新的定位或手动滚动会取消等待。流式回复沿用现有消息更新进入目录，无需刷新。

消息目录从已有 `turns` 计算，使用回合 ID 与消息 ID 区分条目；保留 `buildTurnOutline` 供搜索摘要和分支命名使用，不变更 IPC、Codex 协议或持久化数据。

验证使用隔离配置和模拟 app-server，不涉及真实模型调用：目录单元测试覆盖角色、顺序、多条回复、空白消息、摘要长度与空回合；桌面测试覆盖两类入口、中英文、虚拟列表跳转、长用户输入后的回复定位、流式回复更新，以及原有搜索和分支导航。
