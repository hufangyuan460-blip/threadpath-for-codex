Beta.3 adds build provenance and release verification, preserving Beta.1 conversation branches, workspace labels, and archival. Beta.2 failed release validation and was not published; its tag is retained.

- Click “ThreadPath for Codex” at the top left to view the app version, full source commit, and build status.
- Each version has its own installer, build manifest, and SHA-256 checksum file; published assets are never replaced.
- Release checks verify clean source, version/tag consistency, packaged content, checksums, and conversation flows in the packaged executable.
- Generated electron-vite configuration files are precisely ignored, preventing false dirty-source detection; E2E tests independently compare build metadata against actual Git state.

Requires an installed and authenticated Codex CLI. The Windows installer is unsigned; automatic updates are not available.
