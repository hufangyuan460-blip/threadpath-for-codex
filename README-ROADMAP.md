# ThreadPath for Codex — README 路线图

ThreadPath for Codex 是一个面向 Codex CLI/app-server 的独立 Electron 桌面客户端。MVP 聚焦于线性对话，以及用于快速导航的可视化回合大纲（Turn Outline）。

## 路线图

- [x] **M0 — 桌面应用外壳：** 建立 pnpm workspace、Electron/Vite/React/TypeScript 三层结构，启用 context isolation 和禁用 renderer Node 集成；不连接 app-server。
- [x] **M1-A — app-server 生命周期接入：** 由 Electron 主进程管理连接、初始化、关闭和重连，preload 仅暴露连接状态和受限操作。
- [x] **M1-B — 线程列表与读取：** 通过主进程类型化服务加载线程列表并读取安全元数据；暂不展示消息正文、工具输出或流式内容。
- [x] **M2-A — 只读线性对话渲染：** 按回合顺序显示用户、助手、系统和工具状态的安全纯文本，并保留稳定回合锚点；暂不支持流式更新、Markdown、搜索和大纲。
- [x] **M2-B — 发起回合与流式更新：** 支持一次发送一个纯文本回合，接收白名单通知并去重显示 delta、完成、失败和中断状态；暂不支持取消和工具审批。
- [x] **M3-A — 回合大纲与点击跳转：** 生成安全回合标签，支持键盘/点击跳转到稳定回合锚点；暂不支持滚动联动高亮、搜索、分页和虚拟化。
- [x] **M3-B — 滚动联动与当前回合高亮：** 根据确定性可见性规则同步活动回合、高亮大纲并自动跟随；暂不支持搜索、分页和虚拟化。
- [x] **M3-C — 已加载回合搜索：** 仅搜索当前线程已加载内容，支持中英文不区分大小写匹配、结果排序、防抖和跳转；不搜索跨线程或未加载页面。
- [x] **v0.0.1 — 协议验证：** 启动与关闭 app-server、JSONL/JSON-RPC 请求关联、流式通知、服务端请求错误回复、错误分类，以及可重复的 fake-server 验证。
- [ ] **v0.0.2 — 协议客户端稳定化：** 提炼可复用的类型化客户端 API、版本化协议 fixture、脱敏诊断事件日志，并通过真实回合验收。
- [ ] **v0.1.0 — 线性基础：** app-server 连接、线程/回合加载、流式对话视图、回合大纲、点击跳转、滚动联动高亮、搜索、分页和虚拟化。
- [ ] **v0.2.0 — 稳定性强化：** 更丰富的搜索、诊断能力、性能改进、无障碍优化和发布自动化。
- [ ] **v0.3.0 — Fork 基础：** 支持分支的领域模型和适配器能力检测。
- [ ] **v0.4.0 — 树视图：** 在保留线性投影的同时，可视化线程和回合的祖先关系。
- [ ] **v0.5.0 — 图与比较：** DAG 投影、分支比较和合并预览基础能力。
- [ ] **v1.0.0 — 稳定桌面版：** 受支持的打包方式、迁移策略和生产就绪能力。

有关架构、需求、测试门禁、CI/CD、版本管理以及未来树/DAG 设计约束，请参阅 [SPEC.md](SPEC.md)。
